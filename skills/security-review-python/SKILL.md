# Security Review - Python

Use this skill for Python security reviews.

## Security Checks

- inspect authorization and authentication boundaries
- verify input validation and output encoding
- review secrets handling, settings, and dependency exposure
- check subprocess use, deserialization, file access, and network access for unsafe behavior
