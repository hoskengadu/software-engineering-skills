# Security Review - Java

Use this skill for Java security reviews.

## Security Checks

- inspect authorization and authentication boundaries
- verify input validation and output encoding
- review secrets handling, configuration, and dependency exposure
- check serialization, reflection, file access, and network access for unsafe behavior
