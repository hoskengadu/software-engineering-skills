# Security Review - .NET

Use this skill for `.NET` security reviews.

## Security Checks

- inspect authorization and authentication boundaries
- verify input validation, output encoding, and model binding assumptions
- review secrets handling, configuration, and dependency injection exposure
- check serialization, reflection, and file or network access for unsafe behavior
