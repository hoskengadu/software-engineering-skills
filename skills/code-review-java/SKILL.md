# Code Review - Java

Use this skill for Java reviews.

## Review Checks

- verify exception handling and resource management
- inspect mutability, threading, and shared state
- check null handling and contract boundaries
- look for framework misuse in controllers, services, repositories, and configuration
- assess reflection, serialization, and external integration code for security risk
