# Testing and Coverage - Python

Use this skill for Python testing work.

## Testing Focus

- cover public behavior and domain rules with unit tests
- add integration tests for framework boundaries, persistence, and external dependencies when risk justifies it
- prefer deterministic tests and explicit assertions
- validate exception paths, validation rules, and context-managed resource handling where applicable
