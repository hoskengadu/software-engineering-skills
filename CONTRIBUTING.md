# Contributing

Obrigado por contribuir com este repositório.

## Princípios

- Preserve o foco em qualidade, segurança e evidência.
- Evite inventar regras que não estejam no código, no README ou na descrição da skill.
- Faça mudanças pequenas e coerentes com a estrutura já existente.
- Atualize documentação sempre que um comportamento de uso mudar.

## Fluxo sugerido

1. Abra uma issue ou descreva claramente a melhoria desejada.
2. Confirme a tecnologia alvo quando a skill depender de `.NET`, `Java` ou `Python`.
3. Atualize a skill, o README e o changelog quando necessário.
4. Valide a estrutura do pacote antes de propor merge.
5. Use merge request para revisão antes de qualquer mudança na branch principal.

## Critérios de qualidade

- instruções claras e curtas
- sem contradições entre README, `SKILL.md` e metadados
- sem promessas de segurança ou completude sem validação
- sem duplicação desnecessária

## Governança

- somente o responsável pelo repositório deve aprovar e mesclar na branch principal, se essa for a política adotada no projeto hospedeiro
- mantenha a branch principal protegida
- não faça alterações destrutivas sem necessidade explícita
